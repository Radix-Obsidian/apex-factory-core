# Build in Public — our real log

This is our public build log. Everything we ship, document here first — **the wins and the misses, in plain English, backed by real numbers.**

We're using it to teach people the proper way to design, test, build, and ship AI-native companies and products. Not theory. Receipts.

## The rules (don't break these)

1. **Plain English. No jargon.** If a smart 15-year-old can't follow it, rewrite it. Explain the one or two technical words you can't avoid.
2. **Always show the data.** Time, cost, counts, before/after. A claim without a number is a vibe, not a win.
3. **Document the bad too.** A failure we caught honestly is a win. The day we hide a miss is the day this log becomes marketing.
4. **One lesson per entry.** Every post teaches one clear thing about *design, test, build, or ship.*
5. **Small wins count.** "A test went green" is worth logging. Momentum compounds.

## Format for each entry

- **What happened** — one sentence.
- **The story** — plain English, start to finish.
- **The numbers** — the data that backs it.
- **The lesson** — what it teaches about building AI-native products.
- **Good & bad** — honestly, both.
